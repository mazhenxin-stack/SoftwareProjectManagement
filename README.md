# 校园活动报名与签到管理系统

> 《软件项目管理》课程综合实验项目仓库
>
> 项目仅围绕项目管理过程展开，不进行完整业务系统开发。

## 1. 项目背景
学校希望建设一套轻量级"校园活动报名与签到管理系统"，支持活动信息发布、学生报名、名单审核、二维码签到和签到统计导出。本仓库用于本组在该题目背景下完成项目初始化、范围计划、进度计划、配置管理与协作过程的全部项目管理交付物。

## 2. 项目目标
- 形成围绕交付物的三级 WBS。
- 形成可执行的简化进度计划（关键活动、工期、前置关系、责任人）。
- 形成可落地的配置管理方案（配置项、分支策略、合并规则、版本留痕）。
- 通过多分支协作完成一次真实的冲突制造与解决。
- 由全体成员共同提交并合并总结报告至 `main` 分支。

## 5. 分支约定
- `main`：受保护分支，存放最终提交版本，仅由项目经理执行合并。
- `dev`：阶段集成分支，所有 feature 分支先合并到此处。
- `feature-*`：成员个人功能分支，命名形如 `feature-charter`、`feature-wbs`、`feature-schedule`、`feature-config`、`feature-collab`。
